指针，看得见 & *

一段 84 秒的动画，从内存格子讲到空指针。点播放，或者点下面的章节跳着看。

0:00 / 1:24

完整代码 main.cpp

#include <iostream>
using namespace std;

int main() {
    int a = 42;
    int* p = &a;         // p 存的是 a 的地址

    cout << &a << endl;  // a 的地址
    cout << p  << endl;  // 和上一行一样
    cout << *p << endl;  // 42

    *p = 100;            // 通过 p 修改 a
    cout << a  << endl;  // 100

    int* q = nullptr;
    if (q != nullptr) {  // 用之前先判空
        cout << *q << endl;
    }
    return 0;
}

真实运行结果

0x7fff49acc984
0x7fff49acc984
42
100

前两行一模一样，说明 p 里存的就是 a 的地址。真实地址又长又随机，每次运行都不同；动画里的 0x1008 是为了好看的简化版。

这段动画是怎么做的

整段动画只有一个核心函数 render(t)：给它一个时间 t（秒），它就画出那一刻的画面。播放就是每一帧让 t 增加一点，拖进度条就是直接改 t。

网上那些 Opus 5.5 视频用的也是这个思路，区别是它们最后把每一帧导出成 MP4。你学完 C++ 基础后，可以试着自己写一个。
